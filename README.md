# Policy Compliance Audit

## Overview

This project simulates a policy language publishing process and performs compliance audits using Python, Power Query, and Excel.
The solution focuses on identifying publishing errors, validating policy language requirements, and providing reporting dashboards for compliance monitoring.

---

## Operational Compliance Audits

Business Question: Did we publish all required clauses correctly?

Audits:

- Missing Clause
- Duplicate Clause
- Version Mismatch

Outputs:

- missing_clause.csv
- duplicate_clauses.csv
- version_mismatches.csv
- audit_summary1.csv

---

## Policy Language Compliance Audits

Business Question: Did we publish valid policy language?

Audits:

- Unexpected Clause Loaded
- Wrong State Clause
- Invalid Product Mapping
- Expired Clause

Outputs:

- unexpected_clause_loaded.csv
- wrong_state_clause.csv
- invalid_product_mapping.csv
- expired_clause.csv
- audit_summary2.csv

---

## Tools Used

- Python (Pandas)
- Microsoft Excel
- Power Query

## Reports and Dashboards

### Operational Compliance Audit

KPIs:

- Missing Clauses

### Policy Language Compliance Audit

KPIs:

- Total Findings
- Policies Impacted
